Every numbered item of [PLAN.md](../PLAN.md), so a number cited in the docs, the code or a commit can be looked up here: its name, its status in the plan's own words (its table's status column where there is one, otherwise its item line), the plan's section that defines it, and its record in [`docs/design/`](design/) (its design, steps as built and known limits) once there is one. The letters are the plan's series: O, optional features (Phase 6b, §4 #6); F, expected features (Phase 6c, §4 #7); H, hardening (Phase 7); X, personalisation, effects and discovery (Phase 7b); D, documentation (Phase 7c); N, more features, proposed (Phase 7d); M, maintenance scripts (§9.2). This page is generated by `scripts/plan-items.py` from the plan and the design notes, so don't edit it: change the plan, then rerun the script (`check-all.py --quick` fails while the page is stale).
