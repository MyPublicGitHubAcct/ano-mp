# ano-mp User Guide

ano-mp is a music player for the Mac. It plays the music files you already
have, keeps them in a library you can browse and search, and can look up
covers, album details and biographies online.

This guide explains how to use it. It is also in ano-mp itself: choose
**Help › ano-mp Help**. You don't need to know anything about how
it is built. Each chapter starts with what you can do there, then gives the
steps, then the details.

Buttons, menus and settings are named exactly as ano-mp shows them, in
**bold**. "›" separates the steps of a menu path: **Controls › Repeat ›
All** means "open the Controls menu, then Repeat, then choose All".
Keyboard shortcuts use the Mac's symbols: ⌘ Command, ⌥ Option, ⇧ Shift,
⌃ Control.
