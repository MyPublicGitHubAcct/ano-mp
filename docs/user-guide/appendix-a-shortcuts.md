# Appendix A. Keyboard shortcuts

The same list is in ano-mp: **Help › Keyboard Shortcuts** (⌘/), or
**Keyboard shortcuts…** in **Settings › General**.

## Everywhere

These are the menus' shortcuts. They work wherever you are in ano-mp, even
while typing in the search box.

| Action | Menu | Keys |
|---|---|---|
| Play or pause | Controls › Play | Space |
| Next | Controls › Next | ⌘→ |
| Previous | Controls › Previous | ⌘← |
| Increase volume | Controls › Increase Volume | ⌘↑ |
| Decrease volume | Controls › Decrease Volume | ⌘↓ |
| Stop after this track | Controls › Stop After This Track | ⌥⌘. |
| Record | Controls › Record | ⌥⌘R |
| Go to Current Track | Controls › Go to Current Track | ⌘L |
| Settings… | ano-mp › Settings… | ⌘, |
| Add Folder to Library… | File › Add Folder to Library… | ⇧⌘O |
| Open Files… | File › Open Files… | ⌘O |
| New Playlist | File › New Playlist | ⌘N |
| New Smart Playlist… | File › New Smart Playlist… | ⌥⌘N |
| Get Info | File › Get Info | ⌘I |
| Find | Edit › Find | ⌘F |
| Home | View › Home | ⌘1 |
| Library | View › Library | ⌘2 |
| Favourites | View › Favourites | ⌘3 |
| Now Playing | View › Now Playing | ⌘4 |
| Queue | View › Queue | ⌘5 |
| Visualizer | View › Visualizer | ⌘6 |
| Show or Hide the Queue Panel | View › Show or Hide the Queue Panel | ⌥⌘Q |
| Mini Player | View › Mini Player | ⌥⌘M |
| Keyboard Shortcuts | Help › Keyboard Shortcuts | ⌘/ |

Space plays and pauses unless you are typing in a text field.

These menu items have no shortcut: **Import Playlist…**, **Export
Playlist…**, **Import Library Data…**, **Export Library Data…**,
**Shuffle**, **Repeat**, **Sleep Timer** and **ano-mp Help**.

In the Help window, ⌘[ (or Esc) goes back to the page before.

## In lists and the player

| Action | Keys |
|---|---|
| Back 5 seconds | ← |
| Forward 5 seconds | → |
| Select the row above or below as well | ⇧↑ or ⇧↓ |
| Select every row | ⌘A |
| Add a row to the selection | ⌘-click |
| Select a range of rows | ⇧-click |
| Open the selection's menu | ⇧F10 (or right-click) |
| Open a group, or play from a track | Return |
| Remove from the queue or playlist | Delete |
| Back, or leave full screen | Esc |
| Clear the search box | Esc (in the box) |

## In the visualizer

| Action | Keys |
|---|---|
| Next visualization | V |
| Previous visualization | ⇧V |
| Visualizer full screen | F |
| Leave full screen, or close the visualizer | Esc |

## In Settings

| Action | Keys |
|---|---|
| Next or previous section | ↓ or ↑ (in the list of sections) |
| Close Settings | Esc |
